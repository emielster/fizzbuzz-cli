# fizzbuzz-cli

A simple implementation in Rust, of the infamous [fizzbuzz](https://en.wikipedia.org/wiki/Fizz_buzz) problem.

## Installation

### From crates.io

To install `fizzbuzz-cli` from [crates.io](https://crates.io/fizzbuzz-cli/0.1.0), please run the following:

```bash
cargo install fizzbuzz-cli
```

To verify that the installation was successful, please run:

```bash
fizzbuzz-cli -V
```

### From source

You can also install and build `fizzbuzz-cli` from source.

```bash
git clone https://github.com/emielster/fizzbuzz-cli
cd fizzbuzz-cli
cargo install --path . 
```

To verify that the installation was successful, please run:

```bash
fizzbuzz-cli -V
```

## Usage

Run the command followed by the maximum number you want to evaluate (default is `10`).

```bash
fizzbuzz-cli 15
```

## Options & flags

- `[max]` The maximum number to count up to. (Default: `10`)
- `-h, --help` Print help documentation cleanly generated by [`clap`](https://crates.io/crates/clap)
- `-V, --version` Print installed version

## Example

Running `fizzbuzz-cli 5` will output:
```text
1
2
Fizz
4
Buzz
```

## API 

This CLI package also exposes a library crate, so you can use the underlying logic in your own Rust crates.

Add the dependency to your `Cargo.toml`:
```toml
[dependencies]
fizzbuzz-cli = "0.1.1"
```

An example of how you can use it:

```rust
use fizzbuzz::fizzbuzz;

fn main() {
  let result = fizzbuzz(3);
  assert_eq!(result, "Fizz");
}
```

## Unit & doc tests

Execute the following to run the unit tests and documentation tests inside the library crate:

